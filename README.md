# 镜像人生（Mirror Life）· DSH 插件 MVP v0.8.0

把「身体健康 / 家庭关系 / 本职工作 / 个人爱好」四条线拆成**今天能做的动作**；
工作中的每个日常任务：写一段**工作内容描述** → 自动生成一张**可编辑的工作流示意图** → 一键生成**智能体工作区** → 分别登记**成果模板、知识库、数据库**（上传文件或加外部链接），agent 进到工作区就按这些输入干活。

v0.7.0 的三件事：补上「先照顾好自己、再照顾好家人」的节奏与周计划（含农历节日）；把上传口里的「填本机路径」换成**外部网络链接**；左侧目录里的每个人 / 每个任务 / 每个爱好都**点一下就能直接打开**。

岗位对标基线不再需要手选：填「公司 + 公司业务/行业 + 岗位」，插件按关键词**自动检索**生成「岗位族 + 行业 + 公司类型」三组能力基线。

v0.8.0 加的是**身体健康**这一条线（目录里排在家人前面）：上传 / 粘贴体检报告 → 自动拆成健康指标（对照参考区间标出偏高偏低）→ 按指标、BMI、睡眠与体检间隔给一份「需要注意」。

## 安装

1. 把整个目录放到 DSH 工作区里（例如 `<工作区>/mirror-life-plugin`），不需要 `npm install`——插件无构建步骤、无第三方依赖。
2. 安装为 bundle：

```
plugin_manager action=install_bundle target=<插件目录绝对路径>
```

3. 返回 `"application":"applied"` 即生效。刷新页面，左侧面板列表「自动化任务」下面出现**镜像人生**，点开即用。
4. 升级时改完文件：`plugin_manager action=set_bundle target=@local/mirror-life enabled=false` 再 `enabled=true`（只刷新页面不必重装）。

环境要求：DeepSeek Harness（Web UI 版本；插件用到 `settings` / `sidebar` 客户端槽位与 Host 的 `webServer`、`workspaceRegistry` 服务），Node 18+。

## 入口

左侧面板列表里的**镜像人生**图标，位置紧跟在「**自动化任务**」下面（order 15）。

点开就是整页界面，页面内自带左侧目录树：

```
镜像人生                    « 收起
├─ 总览            ← 最近 7 天的生日/节日 + 四条线的下一步
├─ 健康    (N)     ← 每项要关注的指标一条（偏高/偏低优先）
├─ 家庭    (N)     ← 每位家人一条（未填生日会标出来）
├─ 工作    (N)     ← 每个任务一条（已生成工作区的标「有工作区」）
└─ 爱好    (N)     ← 每个爱好一条
```

- **目录里的对象可以直接点开**：点「妈妈 / 每周广告数据复盘 / 跑步」这类子条目，会切到对应页、把那一条用强调色描边并滚到屏幕中间；任务若已生成过工作区，会自动展开（不用再点「展开」）。
- **每组目录可单独收起**：家庭/工作/爱好右侧各有一个小箭头，点一下收起该组的子条目（组头数字还在），再点展开；状态记在本机。
- **目录可收起**：点目录右上角「«」把它收成 64px 宽的迷你栏（只剩「总/健/家/工/爱」字符），再点「»」展开；状态记在本机，下次打开还是你上次的样子。
- **配色可换**：右上角一排色点（跟随应用主题 / 暖橙 / 青绿 / 靛蓝 / 玫瑰），改的是本页的强调色、页头渐变、按钮、目录选中态与统计卡顶部条，深浅色模式都跟着应用走；选择存在本机。
- **整页底色不再纯白**：用主题色给页面底染一层淡色（`color-mix` 与 `--ml-accent` 混色），再叠两团柔光，换配色时底色会跟着变色。
- **页头那句励志语可以自己写**：默认「工作是为了更好的工作」，点一下就地变成输入框，回车或「保存」生效，最多 60 字，存在本机；留空会自动回到默认句。

## 先照顾好自己：节奏与周计划（总览）

- **我的节奏**卡：填「每周给家庭 h / 每周工作 h / 睡眠底线 h」+「本季度第一优先（家庭·工作·爱好·身体）」，下面会生成一句判断，例如「每周给家庭 8 h，平均到 3 位家人约 2.7 h/人；本周先把家庭放在第一优先。」——没有这块，「分配时间」只是一句口号。
- **本周关怀计划**（家庭页最下面一张卡，也可从总览跳过去）：按生日、公历/农历节日、经期节点、孩子成长阶段、以及「每位家人一次 20 分钟专注交流」自动排出 7 天内的动作，每条带对象与原因；可逐条打勾（完成划掉）、可「重新生成」、可「清空计划」一键删掉（会先确认一次）。
- **农历节日**：春节 / 元宵 / 端午 / 七夕 / 中秋 / 重阳，用浏览器内置的农历（ICU）换算，不需要逐年维护表；闰月会自动跳过。原生的公历节日（元旦/情人节/母亲节/父亲节/国庆/圣诞）照旧。

## 身体健康（v0.8.0）

- **两个入口都能进**：目录里的「健康」，或总览「四条线的下一步 → 去健康」。
- **上传体检报告**：支持 txt / csv / md / json（体检 App 里一般有「复制报告」，粘到「粘贴报告文本」里更省事）。会从报告文字里认出常见指标：血压（收缩压/舒张压）、空腹血糖、总胆固醇、甘油三酯、低密度/高密度脂蛋白、尿酸、肌酐、谷丙/谷草转氨酶、血红蛋白、白细胞、血小板、促甲状腺激素、总胆红素、心率；另有一些文字型结论会单独列一条（脂肪肝、甲状腺结节、幽门螺杆菌阳性/阴性）。
- **自动判高低**：每项按内置参考区间标成 正常 / 偏高 / 偏低 / 异常，参考值就写在旁边；同名的指标再传一次会覆盖旧的，不会重复堆叠。
- **手动添加**：报告里没有的指标可以自己加（指标名 / 数值 / 单位 / 参考值 `3.9~6.1` 这种写法），填了参考值区间会自动判偏高偏低；每条都能删。
- **身体档案**：身高、体重、最近体检日期；填了身高体重会算出 BMI（中国标准 18.5~23.9 正常 / 24~27.9 偏重 / ≥28 肥胖）。
- **需要注意**：按「异常指标 + BMI + 睡眠底线 + 距上次体检天数」生成一份提示，每条都带具体做法（少盐、戒酒、复查窗口、有氧多少分钟之类）；全部正常时也会给一句维持建议。这些是规则生成的通用建议，**不构成医疗诊断**。
- 限制：PDF / 图片格式浏览器里读不出文字，先另存为 txt/csv，或手动录几条；数据同样只存本机浏览器。

## 家庭 / 爱好

- 家庭：录家人（称呼/关系/生日/爱好/备注）→ 生日倒计时、近 60 天节日、本周关怀排期（每位家人一个 20 分钟固定时段）、30 天内动作清单。
- **年龄标签**：按生日算「N 岁」/「N 岁 M 个月」/「N 个月」，直接标在姓名旁。
- **关系细分**：配偶分「爱人 / 妻子 / 丈夫」三项；**经期记录只给「爱人」和「妻子」**（丈夫、父母、兄弟姐妹、子女都没有这个入口）。
- **性别**：添加家人时可选「女 / 男 / 其他」（也可不填），存下来后显示在姓名旁。
- **经期**：填上次开始日期与周期（21~35 天），自动给出当前阶段（经期 / 卵泡期 / 排卵期 / 黄体期）、第几天、下次预计日期与易孕窗，并配一句关怀提示。
- **成长关注（只有儿子/女儿有）**：关系是儿子或女儿时才有这个入口（其他人即使旧数据里开着也会被自动关掉）；按年龄自动分阶段（婴儿期 / 幼儿期 / 学龄前 / 小学 / 初中 / 高中·成年），每阶段 4 个关注焦点 + 本周一个具体动作，下面还有一个**成长备注**输入框（怕黑、最近学会收拾书包这类自由记录）。
- **家人头像**：点「上传照片」选图，自动居中裁成 160×160、存进浏览器；没传时用姓名首字占位。
- 爱好：12 个内置爱好者点选或自定义 → 每个爱好 2~3 个真实社区入口 + 三步培养路径。

## 工作（v0.4.2 起的工作窗口 / v0.5.1 起的自动基线）

**新增任务走窗口**：点「+ 新增日常任务」弹出一个窗口，填任务名、频次、单次耗时，再写一段**工作内容**（越具体越好；用分号/句号分句，每句都可能变成工作流里的一步）。窗口底部「添加并生成工作流」——添加的同时就按**你的岗位 + 任务名 + 工作内容**生成一张工作流示意图。

**工作流示意图（可编辑）**：任务卡里显示成 `01 收集数据 → 02 核对口径 → …` 的流程，标题行注明步数与生成依据（岗位、任务描述），按钮：

- 「按描述重生成」：改完工作内容后重新推断；
- 「编辑」：逐步改文字、`↑`/`↓` 调顺序、`×` 删掉、`+ 新增一步`。

示意图不是只给人看的——点「一键生成智能体工作流」时它会**写进 `AGENTS.md` 的「工作流」一节**（末尾自动补「自检」「交付」两步），agent 就按这个顺序干活。旧任务没有描述也没关系，打开卡片会按任务名自动推断一版。

**已生成的任务默认折叠**：卡头显示任务名 + `已生成` 徽标 + 频次/耗时，点「展开」才看到示意图、工作区路径与上传口；生成成功的那一刻会自动展开一次（不然你会以为上传口没出来）。

生成之后，成果模板、知识库、数据库三个上传口**排成一行三列**（窄屏自动变一列），每个口都能：

| 上传口 | 落点 | 用途 |
| --- | --- | --- |
| 成果模板 | `成果模板/` | 交付物必须按它的结构写 |
| 知识库 | `知识库/` | 参考资料、历史文档、规范 |
| 数据库 | `数据库/` | csv / xlsx / sqlite，或**外部链接** |

每个口都能「**上传文件**」（可多选，文件复制进工作区）或「**加外部链接**」（登记一个 `http(s)://` 地址，不复制内容），登记完可单个移除。外部链接会写进 `输入清单.md`，`AGENTS.md` 里也写明了调用规则：用联网检索/抓取取正文、不要凭标题猜、取不到就写「链接不可达」，引用要带完整 URL 与访问日期。**本机路径只保留兼容**（旧数据仍能导出与展示），新入口不再提供。

- **最近产出**：工作区里点「最近产出」，直接读 `outputs/` 里最近 5 个文件（名称 / 大小 / 时间）——不再只有「生成」没有「回看」。
- 镜像人生根目录默认 `D:\Deep Seek Harness\工作区\镜像人生`，可在岗位信息卡里改（默认值同时写在 `client.js` 与 `index.js` 的 `DEFAULT_MIRROR_ROOT`，换机器时改这两处）；工作区一律建在 `<根目录>/工作目录/<任务名>` 下。
- **对标基线自动检索**：岗位信息卡填「公司 / 公司业务·行业 / 岗位」，插件按关键词匹配出「岗位族（产品·运营·销售·研发·设计·财务·人力·内容·通用）」+「行业（11 类：电商·软件·制造·教育·医疗·金融·广告·物流·零售·建筑·政务）」+「公司类型（大公司·创业小团队·外企·国企事业单位）」，取岗位族 4 条 + 行业 2 条 + 公司类型 1 条，每条都标来源；改任一项输入即时重算，能力自评就按这份基线打 1~5 级。
- 生成出来的工作区结构：

```
<镜像人生根目录>/工作目录/<任务名>/
├─ AGENTS.md        ← 智能体定义：身份 / 目标 / 工作流（来自示意图）/ 输入与调用规则 / 输出契约 / 自检清单
├─ 任务说明.md       ← 含工作内容与工作流
├─ 输入清单.md       ← 三类输入的总账，上传后自动刷新
├─ 成果模板/         ← 上传口 1
├─ 知识库/           ← 上传口 2
├─ 数据库/           ← 上传口 3
├─ inputs/README.md  ← 取数顺序：成果模板 → 知识库 → 数据库 → 缺口 → 成稿
└─ outputs/          ← 产出落在 outputs/YYYY-MM-DD-<任务名>.md
```

- 工作区会登记进 DSH 工作区列表；「**复制启动提示词**」可直接粘给新会话，agent 会按 `AGENTS.md` 与 `输入清单.md` 干活。
- 一键**导出 Markdown 建议文档**：任务盘点 + 三阶段提效路线 + 能力差距表 + 未来 7 天行动 + 五、成果模板 + **六、工作区与输入**（含工作内容、工作流、三个上传口清单）。

## Host 接口（`index.js`）

| 路由 | 作用 |
| --- | --- |
| `GET /mirror-life/api/health` | 存活检查，返回版本与镜像人生根目录 |
| `POST /mirror-life/api/inspect` | `{path}` → 存在性、是否目录、条目数、扩展名摘要 |
| `POST /mirror-life/api/build` | `{task,profile,template,suggestion,root}` → 建目录写文件、登记工作区，返回路径与启动提示词 |
| `POST /mirror-life/api/upload` | `{dir,root,kind,mode}` → `file` 写文件 / `url` 登记外部链接 / `path` 只登记（兼容） / `remove` 删除，随后刷新 `输入清单.md` |
| `GET /mirror-life/api/outputs` | `?dir=&root=` → 最近产出（`outputs/` 下按时间倒序 5 个） |
| `POST /mirror-life/api/workspace/delete` | `{dir}` → 撤销：只允许删 `镜像人生/工作目录` 下的目录，同时注销工作区登记 |

- 目录守卫生效：所有 `dir` 必须落在 `<root>/工作目录/<一级目录>`，越界返回「工作区不在 镜像人生/工作目录 下」。
- Host 侧服务通过 Cordis `root.inject(['webServer','workspaceRegistry'])` 声明依赖，不用对象级 inject（避免服务缺失时整个插件加载失败）。

## 数据与边界

- 家庭/工作/爱好数据**只存在本机浏览器 localStorage**（`mirror-life:v1`；页签 `mirror-life:tab`），不联网、不上传。
- 家人头像是缩到 160×160 的 JPEG data URL，也占 localStorage：周计划、节奏预算也存在同一份数据里；存几十张没问题，存上百张可能触到浏览器 5 MB 上限（超出时保存会失败，控制台会报 `QuotaExceededError`）。
- 上传的文件是**真复制**进 `<镜像人生>/工作目录/<任务>/<知识库|数据库|成果模板>/`；加的外部链接也只记在 `sources.json` 与 `输入清单.md` 里；本机路径同样只登记（兼容旧数据）。
- ⚠️ 生成的 `AGENTS.md` 会被 DSH 当作附加指令注入**工作目录在该路径下的会话**。如果镜像人生根目录位于你的会话工作区内（默认就是 `D:\Deep Seek Harness\工作区\镜像人生`），生成的工作区会出现在文件的所在树里，注意别写会误导其他会话的内容；删掉工作区后附加指令会自动失效。

## 已知取舍

- 左侧只放**一个**图标，三个子目录在页面内部——左侧面板列是一格一图标，不支持嵌套。
- 不接入日历 / 通讯录；不做账号与多设备同步；界面文案中文硬编码（列表元数据有 `locale/zh.json`）。
- 配色只改本插件页内元素（用 `--ml-*` 变量 + `data-theme`），不覆盖应用全局主题。
- 立体感是纯 CSS 的：分层阴影（`--ml-sh-1/2/3`）、顶部内高光、渐变、悬停上浮、统计卡轻微 `rotateX`、弹窗入场动画；`prefers-reduced-motion` 下动画自动关闭。
- 插件自己**不解析**知识库与数据库内容，只保证 agent 拿到清单、链接与调用规则；真正取数由进到工作区的 agent 做。外部链接需要会话具备联网检索/抓取能力，内网或需登录的链接 agent 取不到会如实报「链接不可达」。
- 建议与工作流示意图都是**规则生成**（没有调用大模型）：示意图按岗位 + 任务名 + 描述里的分句/关键词推断，所以写得越具体越准，也随时可以手改。
